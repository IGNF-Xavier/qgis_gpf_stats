# Statistiques analytiques Géoplateforme — 7.0.0

Statistiques d'usage de la Géoplateforme (API Entrepôt + Stats) pour QGIS : chargement asynchrone avec progression et annulation, cache local, groupes d'offres composables, dashboard interne à niveau d'analyse unique, exports CSV nommés et export XLSX analytique à 9 feuilles.

Documentation complète (guide utilisateur, guide développeur, architecture, routes API, migration depuis la 6.1.0, rapport de tests) : voir le dossier `docs/` de l'archive source, ou le dépôt de sources livré séparément de ce ZIP installable.
